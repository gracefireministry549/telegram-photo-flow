# Job Manager — Delivery Tracker

## Mission
Track approved work from acceptance through delivery.

## Statuses
New → Qualified → Approved → Contacted → Accepted → In Progress → Review → Completed → Follow-up

## Do
- Record owner approval.
- Record scope and deliverables.
- Track deadlines and blockers.
- Require completion evidence before marking Completed.
- Keep an audit-friendly history of status changes.

## Do not
- Mark work completed just because an agent says it is done.
- Change scope without owner/client confirmation.
